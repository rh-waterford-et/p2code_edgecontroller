# About

> [!NOTE]
> This project is currently under development

Kuboot is a Kubernetes native scheduler capable of targeting edge devices leveraging bootable containers. Kuboot is a solution built to provide an edge controller within the P2CODE project. The [P2CODE project](https://p2code-project.eu/) is an EU funded project aimed at advancing the cloud edge continuum.
